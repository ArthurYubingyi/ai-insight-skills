# AI Insight Skills

一套用于消费者研究与市场洞察的开源 AI Skills。

把三十年消费者研究的方法论,封装成 AI 可以直接调用的能力。不是教你用工具,是把"怎么做研究"这件事本身固化下来,让 AI 按专业方法论替你工作。

## 这是什么

每一个 Skill 都是一套结构化的研究方法论,封装成 Claude Skill 格式(也兼容其他大模型的指令使用)。它们解决的不是"AI 怎么生成内容",而是"AI 怎么按照专业研究流程思考"。

适合:消费者研究从业者、品牌洞察团队、市场研究人员,以及任何需要把模糊的商业问题变成可执行研究方案的人。

## Skills 列表

| Skill | 解决的问题 | 状态 |
|---|---|---|
| **research-problem-definition** 界定研究课题 | 把一句模糊的研究需求("想了解年轻人为什么不买")拆解成结构清晰、可指导决策的研究框架 | ✅ 可用 |
| 行业快速扫描 | 30 分钟生成一份可用的行业扫描简报,替代两天的桌面研究 | 🔜 即将上线 |
| 洞察生成 | 从消费者访谈或行为观察中,提炼出没说出口的需求与机会 | 🔜 即将上线 |
| 产品线规划 | 基于市场机会矩阵,规划差异化的产品线布局 | 🔜 即将上线 |

## 怎么用

### 方式一:在 Claude 中安装(推荐)

1. 下载对应 Skill 文件夹下的 `SKILL.md`,或 Releases 里打包好的 `.skill` 文件
2. 在 Claude 设置中:Settings → Capabilities → Skills → 上传
3. 安装后,当你在对话中遇到相关研究场景,Claude 会自动调用,或用斜杠命令手动触发

### 方式二:作为提示词模板使用

如果你用的是其他大模型,可以直接把 `SKILL.md` 正文中的方法论部分复制到对话框,作为指令使用。

## 设计原则

- **方法论优先,不是工具教程**:每个 Skill 封装的是研究的思维框架,不是某个工具的操作步骤
- **从源头解决问题**:研究做错方向,往往不是方法错了,是课题没界定清楚。这套 Skills 特别重视研究的源头
- **可指导决策**:每个输出都以"能不能支持一个真实的商业决策"为标准
